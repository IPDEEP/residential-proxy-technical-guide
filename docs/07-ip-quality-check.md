# 07｜IP 质量检测主要看哪些指标？

IP 质量不是单一分数。实际评估应结合网络可用性、地址信息、服务稳定性和业务需求。

## 1. 常见检测维度

| 指标 | 说明 | 注意事项 |
|---|---|---|
| IP 地址 | 当前请求使用的出口地址 | 不同协议或应用可能走不同出口 |
| ASN | IP 所属自治系统 | ASN 不能单独证明住宅属性 |
| ISP / Organization | 数据库记录的组织或运营商 | 数据源之间可能不同 |
| 地理位置 | 数据库估算的国家、地区或城市 | 不等同于设备真实位置 |
| 网络类型 | 住宅、移动、托管等分类 | 分类依赖数据源和规则 |
| 延迟 | 请求或网络往返耗时 | 受目标位置、路由和负载影响 |
| 可用性 | 一段时间内成功连接的比例 | 需要定义测试窗口和样本 |
| 风险信息 | 某些数据库提供的信誉或风险信号 | 不同服务评分不可直接横向比较 |

## 2. 建议的检测流程

1. 确认测试设备和网络环境。
2. 确认目标应用确实使用了待测代理。
3. 记录出口 IP 和检测时间。
4. 查看 ASN、ISP、地理位置等信息。
5. 使用多个数据源交叉检查。
6. 在一段时间内进行重复连接测试。
7. 记录延迟、失败率和错误类型。

## 3. 不要只看一个“纯净度分数”

风险分数可能由不同数据源和模型生成，字段定义、样本范围和更新频率并不统一。某个分数不能保证目标平台一定接受该 IP，也不能证明绝对匿名或绝对安全。

## 4. 形成可复现的检测记录

建议保存以下字段：

- 测试日期和时间；
- 操作系统与客户端；
- 代理协议；
- 出口 IP；
- ASN / ISP；
- 检测来源；
- 延迟与连接结果；
- 失败原因；
- 测试持续时间。

不要在公开报告中包含账号密码、客户身份信息或其他敏感数据。
