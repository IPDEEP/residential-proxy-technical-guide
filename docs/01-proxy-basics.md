# 01｜代理 IP 基础知识

## 1. 什么是代理 IP？

代理（Proxy）是一种由中间节点代替客户端向目标服务发起请求的网络通信方式。客户端先连接代理服务，再由代理服务按照协议和配置转发请求。

简化流程：

```text
客户端 / 浏览器
      |
      | 连接代理
      v
代理服务节点
      |
      | 转发请求
      v
目标网站 / API
```

目标服务通常会看到代理出口的网络地址，但实际可见信息还可能受到应用层请求头、连接方式、DNS 解析路径和其他网络配置影响。

## 2. 常见代理类型

### 按网络归属或地址来源理解

- **住宅 IP**：通常指被 IP 数据库或网络注册信息识别为住宅网络相关的地址。不同数据库可能给出不同分类。
- **数据中心 IP**：通常与云服务商、托管机房或数据中心网络相关。
- **移动网络 IP**：通常来自移动运营商网络，可能涉及运营商级 NAT（CGNAT）等架构。

### 按地址使用方式理解

- **静态代理**：在约定服务周期或配置范围内，出口地址保持相对固定。
- **动态代理**：出口地址可按规则变化，例如按请求、会话、时间或资源池策略分配。

这些分类维度不同，不能简单把“住宅 / 机房”和“静态 / 动态”当成同一组概念。

## 3. 代理连接涉及哪些信息？

配置代理时，通常需要确认：

| 参数 | 含义 |
|---|---|
| Host | 代理服务器域名或 IP |
| Port | 代理服务端口 |
| Protocol | HTTP、HTTPS proxy 或 SOCKS5 等 |
| Username | 认证用户名（如需要） |
| Password | 认证密码（如需要） |
| Session | 会话或粘性会话设置（如产品支持） |

实际参数和认证方式应以服务提供方的控制台或技术文档为准。

## 4. 代理不等于 VPN

代理通常由应用或指定网络请求使用；VPN 常通过虚拟网络接口或系统路由接管一定范围的网络流量。不同产品的实现有差异，不能仅凭名称判断覆盖范围或安全属性。

## 5. 使用代理前的检查

1. 确认服务来源和使用授权。
2. 核对协议、地址、端口和认证方式。
3. 确认目标应用是否支持该协议。
4. 先用非敏感请求验证连接。
5. 检查日志和截图，避免泄露凭据。
6. 根据业务需求记录延迟、稳定性和错误率。
