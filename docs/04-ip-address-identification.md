# 04｜IP 地址识别基础

IP 地址用于在 IP 网络中标识网络接口或通信端点。常见版本包括 IPv4 和 IPv6。

## 1. IPv4 与 IPv6

- **IPv4**：通常以四组十进制数字表示，例如 `192.0.2.10`。示例地址来自文档用途的保留地址段，不应用作真实公网节点。
- **IPv6**：使用十六进制分组表示，地址空间远大于 IPv4。

实际网络可能同时支持 IPv4 和 IPv6，也可能只支持其中一种。

## 2. IP 查询通常能看到什么？

常见 IP 查询服务可能提供：

- IP 地址；
- 国家、地区或城市估算；
- ASN；
- ISP 或 Organization；
- 网络类型或用途分类；
- 时区、经纬度估算；
- 风险或信誉类指标（视服务而定）。

并非每个服务都会提供全部字段，也不代表这些字段都具有同样的准确度。

## 3. 为什么 IP 地理位置可能不准确？

IP 地理位置通常是基于数据库估算，而不是通过 IP 地址直接读取设备 GPS。误差可能来自：

- 数据库更新滞后；
- 运营商地址分配和调度；
- 企业网络出口集中；
- 移动网络和 CGNAT；
- VPN、代理或云网络；
- IP 地址段重新分配。

因此，城市级定位不应被当作精确物理位置证明。

## 4. 查询结果如何交叉验证？

建议至少记录：

1. 查询时间；
2. 查询服务和数据源；
3. ASN / ISP 信息；
4. 地理位置结果；
5. 不同服务的差异；
6. 业务实际网络测试结果。

如果不同检测网站结论不一致，应先确认字段定义和数据更新时间。
