# 09｜如何根据业务需求选择代理 IP？

选择代理资源时，先明确业务任务，再评估网络类型、地址变化方式、协议、地区、计费和技术支持。

## 1. 先定义任务

建议先回答：

- 是固定出口需求，还是需要动态分配？
- 是否有明确的国家或地区要求？
- 使用 HTTP、HTTPS 还是 SOCKS5？
- 需要多少并发连接？
- 每月预计消耗多少流量？
- 是否需要会话保持？
- 是否需要白名单或特定认证方式？
- 是否有合规、审计和数据保护要求？

## 2. 按资源类型初步比较

| 资源类型 | 常见特点 | 需要重点确认 |
|---|---|---|
| 静态住宅 IP | 出口地址在约定范围内相对固定 | 地址持续性、网络归属、计费周期 |
| 动态住宅代理 | 出口地址按服务规则变化 | 流量计费、轮换规则、会话策略 |
| 移动代理 | 使用移动运营商网络相关资源 | 地区、运营商、会话和套餐规则 |
| 数据中心代理 | 常见于服务器和云网络场景 | 带宽、路由、资源稳定性 |
| VPS | 提供可管理的虚拟服务器环境 | CPU、内存、存储、带宽和系统 |

VPS 与代理 IP 是不同类型的产品，不能混为一谈。

## 3. 比较成本时要统一口径

例如比较按 IP 计费与按流量计费时，应估算：

- 资源数量；
- 使用周期；
- 预计流量；
- 并发需求；
- 超额费用；
- 是否需要额外功能；
- 维护和管理成本。

不要仅比较单价，而忽略计费单位和使用限制。

## 4. 采购前核对清单

- [ ] 产品协议是否符合客户端要求？
- [ ] 地区是否有明确库存和说明？
- [ ] 计费单位和周期是否清楚？
- [ ] 是否有并发、流量或会话限制？
- [ ] 认证方式是否适合团队管理？
- [ ] 是否提供连接测试和技术支持？
- [ ] 服务条款和使用范围是否明确？
- [ ] 价格是否为当前有效价格？
