# 03｜静态住宅 IP 与动态住宅代理有什么区别？

静态与动态描述的是出口 IP 的分配和变化方式。住宅与数据中心描述的则是网络资源背景。这是两个不同维度。

## 1. 静态住宅 IP

静态住宅 IP 通常指在约定服务周期或配置范围内，出口地址保持相对固定的住宅网络相关代理资源。

可能适合：

- 需要固定出口地址的远程业务环境；
- 长期地区网络质量观察；
- 固定来源地址的系统访问测试；
- 需要将某个出口地址纳入企业网络管理流程的场景。

具体地址是否长期不变、是否独享、资源如何维护，必须以实际套餐规则为准。

## 2. 动态住宅代理

动态住宅代理通常通过资源池分配出口 IP，地址可能根据请求、会话、时间或服务端策略变化。

可能适合：

- 多地区网络可用性测试；
- 大量合法公开页面的可访问性检查；
- 需要按流量计费的网络任务；
- 需要观察不同出口网络表现的测试工作。

IP 更换频率、会话保持时间、可用地区和计费规则因服务而异。

## 3. 对比

| 维度 | 静态住宅 IP | 动态住宅代理 |
|---|---|---|
| 出口地址 | 通常保持固定 | 按服务规则变化 |
| 会话 | 适合固定出口需求 | 可能支持轮换或粘性会话 |
| 计费方式 | 常见按 IP / 周期计费，具体以套餐为准 | 常见按流量计费，具体以套餐为准 |
| 适用任务 | 固定出口、长期环境测试 | 多地区测试、动态出口需求 |
| 重点检查 | 地址持续性、线路和资源属性 | 流量消耗、轮换规则和会话策略 |

## 4. 速度和风控不能只看静态或动态

静态地址不一定比动态地址快。速度与路由、带宽、目标位置、网络拥塞和服务端负载等因素有关。

同样，静态或动态都不能保证某个平台一定接受连接或通过审核。平台可能综合评估账号行为、设备环境、请求模式、网络历史和自身政策。

## 5. 选型前需要确认的问题

- 是否必须保持同一个出口地址？
- 是否需要多个地区的出口？
- 任务预计产生多少流量？
- 是否需要粘性会话？
- 是否有并发、白名单或协议要求？
- 价格如何计算，是否存在额外限制？
