这个计算器可以做什么？

不同代理产品的计费方式并不相同：静态住宅 IP 通常按 IP 数量和租用周期估算；动态住宅代理需要结合流量用量；VPS 则需要考虑实例数量、配置和租用时长。本表格把这些输入项放在一起，帮助你建立初步预算。

支持估算的产品类型

  • 静态住宅 IP：填写需要的 IP 数量、使用月数和每条 IP 的月单价。
  • 动态住宅代理：填写预计每月使用的 GB 数、使用月数和每 GB 单价。
  • VPS：填写实例数量、使用月数和每台 VPS 的月单价。
  • 自定义项目：移动代理、不限量住宅代理或其他费用可以在表格中自行填写实际套餐价格。

如何使用

  1. 打开 Google Sheets 计算器，按提示创建自己的副本或在有权限的情况下使用表格。
  2. 修改蓝色输入项，包括数量、每月流量、使用月数和单价。
  3. 查看周期总费用、月均费用及各产品费用分项。
  4. 将估算结果与目标地区、实际套餐、计费规则和购买页面进行核对。

计算方式

  • 静态住宅 IP 费用 = IP 数量 × 使用月数 × 每 IP 每月单价。
  • 动态住宅代理费用 = 每月 GB 用量 × 使用月数 × 每 GB 单价。
  • VPS 费用 = 实例数量 × 使用月数 × 每台每月单价。

当前模板中的参考起价为静态住宅 IP $1.50/IP/月、动态住宅代理 $0.50/GB、VPS $1.04/月。它们仅用于初始估算；地区、资源、配置、套餐和促销可能影响最终价格。移动代理与不限量住宅代理没有设置统一默认价，需要按实际套餐填写。

计算结果仅用于预算规划，不构成报价或订单金额。模板未自动计入税费、折扣、赠送流量、最低消费、超额费用及地区差价。最终费用以 IPDEEP 官网和购买页面显示为准。

常见问题

这个代理 IP 成本计算器免费吗？

可以通过公开链接查看表格。你可以根据 Google Sheets 的权限选项复制一份到自己的云端硬盘，再修改输入项。

计算结果是 IPDEEP 的正式报价吗？

不是。计算器用于预算估算，实际价格会因地区、资源类型、套餐和配置不同而变化，请以官网实时信息为准。

动态住宅代理应该填写多少流量？

建议根据业务测试或历史账单估算每月 GB 用量。如果每个月的使用量差异较大，可以分别计算不同月份的预算，再进行汇总。

可以计算多个产品组合吗？

可以。表格提供静态住宅 IP、动态住宅代理、VPS 和自定义项目输入行，可将不同类型的资源放在同一份预算中估算。
