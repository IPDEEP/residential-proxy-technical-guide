使用前先确认

  • 服务端支持的代理协议及端口；
  • 是否使用用户名密码认证或 IP 白名单；
  • 客户端是否支持 HTTP、SOCKS5 或 SOCKS5h；
  • DNS 解析发生在本地还是代理侧；
  • 测试目标是否允许当前网络环境访问。
代理端点 TCP 可连接，不代表认证、隧道建立和目标网站访问都成功。请分阶段验证。
