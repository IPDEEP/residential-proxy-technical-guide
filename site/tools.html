IPDEEP TECHNICAL HUB

实用工具与代码示例

三个轻量工具分别面向 IP 列表整理、代理端点初步诊断和 Linux VPS 状态检查。工具的检测边界会在对应文档中明确说明。

PYTHON · NO THIRD-PARTY DEPENDENCIES

01. IP List Audit

在本地检查 IPv4 / IPv6 地址格式、地址范围类别和重复项，并生成 CSV 报告。

python examples/ip-list-audit.py ips.txt --output report.csv

查看代码 ↗ · 使用说明 ↗

仅做本地语法和范围分类，不识别住宅、移动、ISP 或数据中心属性，也不判断 IP 信誉。
PYTHON · TCP CONNECTIVITY

02. Proxy Endpoint Checker

交互式输入代理 URL，检查 HTTP、HTTPS、SOCKS5 和 SOCKS5h 端点 TCP 连通性；HTTPS proxy 会额外检查 TLS 握手。

python examples/proxy-endpoint-check.py --timeout 12

查看代码 ↗ · 使用说明 ↗

TCP 连接成功不代表代理认证、协议握手、隧道建立或目标访问成功。工具不检查出口 IP。
BASH · READ ONLY

03. Linux Baseline Audit

在 Linux VPS 上汇总系统资源、失败服务、监听端口、防火墙与 Nginx 状态。脚本只读，不修改系统配置。

bash examples/linux-baseline-audit.sh > baseline-report.txt 2>&1

查看代码 ↗ · 使用说明 ↗

报告可能包含主机名、监听端口和内部路径，对外分享前请检查并脱敏。

工具使用原则

  • 运行前阅读源代码和使用说明；
  • 只在自己拥有或获授权的设备、网络和服务器上执行；
  • 不要把真实代理密码、API Key、SSH 私钥或客户信息提交到公开仓库；
  • 不要将工具输出解释为平台审核、匿名性或安全性的保证。
